Bucket Manager très basique 

**1 - Faire un environnement virtuel**

```
python3 -m venv .venv
.venv/bun/activate
```

**2 - Installer les dépendances** 

```
pip install -r requirements.txt
```

**3 - Definir les variables d'environnement**

dans ~/.aws/credentials

aws_access_key_id
aws_secret_access_key

dans ~/.aws/config 

region
